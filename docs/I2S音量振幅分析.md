# I2S 音量（软件增益）波形振幅验证

> 数据来源：逻辑分析仪抓取的 I2S 波形（`.sal` → 导出 CSV）
> 采集文件：`Max_volume` / `Middle_volume` / `Default_volume`（同目录 `docs/`）
> 分析日期：2026-10-16

## 一、方法与前置

- 通道映射：**SCK = Channel 0，WS/FRAME = Channel 2，SD(数据) = Channel 1**，16bit I2S。
- 采样率：24MHz；解码方式：按 SCK 上升沿采 SD，按 WS 分段取 16bit 字，还原成 **16kHz PCM**。
- 注意两点，否则数据会失真：
  1. I2S 的 **1-bit 延迟**：MSB 在 WS 跳变后一个时钟才到，取字时要跳过第一位，否则高位错位会把样本推到满量程（假性削波）。
  2. 音频只出现在**左声道**，右声道全程为 0。
- 三个音量档（软件增益 `sample * current_volume / 255`）：Max=255、Default=200、Middle=128。

## 二、结论

软件增益确实生效，**波形振幅随档位等比变化**。

| 采集 | 增益 | 峰值 | RMS | 峰值 ÷ 增益 |
|---|---|---|---|---|
| Max | 255 | **15140** | 2649 | 59.4 |
| Default | 200 | **11029** | 2119 | 55.1 |
| Middle | 128 | **7599** | 1332 | 59.4 |

把峰值 / RMS 除以增益档位后，三份基本重合（**RMS 归一化后 Max / Default / Middle ≈ 10.4 / 10.6 / 10.4**；峰值归一化 Max 与 Middle 同为 59.4）—— 说明三者是同一源音频被线性缩放，增益链路按预期工作。峰值上 Default 略低（≈55），应是该段音频自身的瞬时峰值略低，不影响整体结论。
