# 外设引脚说明

---

## INMP441 (MEMS 麦克风模块)

全向 MEMS 麦克风，I2S 接口输出数字音频，**本身是 Slave，依赖主控提供时钟**。

```
        ┌──────────────────┐
   VDD ─┤1                 ├─ GND
   GND ─┤2    INMP441      ├─ L/R
    SD ─┤3     (背面)       ├─ WS
    SCK ─┤4                 ├─ (空)
        └──────────────────┘
```

| 引脚 | 丝印 | 方向 | 用途 | 接线 |
|------|------|------|------|------|
| 1 | **VDD** | 输入 | 供电，1.8V~3.3V | ESP32 3.3V |
| 2 | **GND** | — | 地 | ESP32 GND |
| 3 | **SD** | 输出 | Serial Data，I2S 数据输出 | GPIO2 |
| 4 | **SCK** | 输入 | Serial Clock，即 BCLK（位时钟） | GPIO41 |
| 5 | **WS** | 输入 | Word Select，即 LRCK（左右声道时钟） | GPIO42 |
| 6 | **L/R** | 输入 | 声道选择：GND=左声道，VDD=右声道 | **GND（必须接地！）** |

### 关键细节

- **L/R 必须接地**：悬空不会默认左声道，会导致完全不输出数据。这是 INMP441 最大的坑。
- **只支持立体声协议**：即使只输出一个声道，WS/BCLK 时序也是按立体声跑的。ESP32 设 `I2S_SLOT_MODE_STEREO`。
- **Philips 标准（I2S 格式）**：WS 翻转后延迟 1 个 BCLK 开始传数据，对应 `bit_shift=true`。
- **数据左对齐**：16 位采样数据在 32 位 slot 中靠左，对应 `left_align=true`。
- **模块丝印 VDD/VCC 等价**：不同厂家标法不同，都是电源正极。

### I2S 时序 (16kHz, STEREO, 32-bit slot)

```
BCLK = 16000 × 32 × 2 = 1.024 MHz

WS:   |←───── 左声道 (high) ─────→|←───── 右声道 (low) ──────→|
      |‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾|___________________________|

SD:   --X======XXXXXXXX======XXX--X======XXXXXXXX======XXX--
         ↑                      ↑
      左声道 16bit 数据     右声道 16bit 数据
      (靠左对齐在 32bit slot)
```

## MAX98357A (I2S D 类功放模块)

3W 单声道 D 类功放，I2S 输入，**本身是 Slave，依赖主控提供时钟**。

```
        ┌──────────────────┐
   VIN ─┤1                 ├─ GND
   GND ─┤2    MAX98357A    ├─ SD
  BCLK ─┤3     (背面)       ├─ GAIN
   LRC ─┤4                 ├─ DIN
        └──────────────────┘
```

| 引脚 | 丝印 | 方向 | 用途 | 接线 |
|------|------|------|------|------|
| 1 | **VIN** | 输入 | 供电，2.5V~5.5V | ESP32 3.3V（或 5V 更大音量） |
| 2 | **GND** | — | 地 | ESP32 GND |
| 3 | **BCLK** | 输入 | Bit Clock，位时钟 | GPIO41（和麦克风**共用**） |
| 4 | **LRC** | 输入 | L/R Clock，左右声道时钟 | GPIO42（和麦克风**共用**） |
| 5 | **DIN** | 输入 | Data In，I2S 音频数据输入 | GPIO5 |
| 6 | **GAIN** | 输入 | 增益选择，控制音量 | 悬空=9dB，GND=3dB，VDD=15dB |
| 7 | **SD** | 输入 | Shutdown 控制（高=工作，低=关断） | GPIO4 |

### 关键细节

- **BCLK 和 LRC 与麦克风共用**：INMP441 和 MAX98357A 挂在同一条 I2S 总线上，时钟线并联。这叫全双工模式（full-duplex）。
- **SD 脚不等于 I2S 的 SD**：别搞混——INMP441 的 SD = Serial Data（数据输出），MAX98357A 的 SD  = Shutdown（使能控制）。
- **GAIN 浮空默认 9dB**：如果想更大声接 VDD（15dB，注意削顶），想小声接 GND（3dB）。
- **SD=低电平时功放完全静音**：内部关断，不耗电也不会有任何杂音。比改数据为 0 干净得多。
- **VIN 接 5V 声音更响**：3.3V 也能工作，但输出功率会降低。3W 的最大功率需要 5V 供电。
- **内部自带 LC 滤波**：PWM 调制输出已经滤成模拟信号，直接接喇叭端子就行。

### 共用总线拓扑

```
ESP32 (Master)
 │
 ├── BCLK (GPIO41) ──┬── INMP441 SCK (pin 4)
 │                    └── MAX98357A BCLK (pin 3)
 │
 ├── WS   (GPIO42) ──┬── INMP441 WS  (pin 5)
 │                    └── MAX98357A LRC (pin 4)
 │
 ├── DIN  (GPIO2)  ───── INMP441 SD  (pin 3)    ← 麦克风→ESP32
 │
 └── DOUT (GPIO5)  ───── MAX98357A DIN (pin 5)   ← ESP32→功放
```

## LED（低电平点亮）

| 项目 | 值 |
|------|-----|
| 控制引脚 | **GPIO7** |
| 电平逻辑 | 低电平点亮（active-low） |
| 初始化 | `LED_Init()` |
| 控制 | `Set_Level_LED(PIN, 0)` = 亮，`Set_Level_LED(PIN, 1)` = 灭 |

### 关键细节

- **低电平点亮**：GPIO 输出 0 → 灯亮，输出 1 → 灯灭。初始化默认输出 1（灭）。
- 引脚定义在 `components/LED_and_KEY/led.h`（`#define PIN 7`）。
- 语音指令：`led_on` / `led_off`（服务器检测"开灯/关灯"）。

## 电机 TB6612FNG

| 引脚 | 丝印 | 方向 | 用途 | 接线 |
|------|------|------|------|------|
| 1 | **AIN1** | 输入 | 方向控制 1 | GPIO8 |
| 2 | **AIN2** | 输入 | 方向控制 2 | GPIO9 |
| 3 | **PWMA** | 输入 | PWM 速度控制 | GPIO10 |
| 4 | **STBY** | 输入 | 使能（高=工作，低=待机） | ESP32 3.3V |
| 5 | **VCC** | 输入 | 逻辑电源 2.7V~5.5V | ESP32 3.3V |
| 6 | **VM** | 输入 | 电机电源 2.5V~13.5V | 锂电池正极 |
| 7 | **GND** | — | 地 | 电池负极 + ESP32 GND（共地） |
| 8 | **AO1/AO2** | 输出 | 电机驱动输出 | 电机两根线 |

### 关键细节

- **必须共地**：电池负极、模块 GND、ESP32 GND 三点连成同一个地网络。缺了共地，控制信号没有参考点，电机完全不转。
- **STBY 必须接高**：不接高电平，驱动芯片不工作。
- **VM 用独立锂电池**：开发板 5Vm 引脚带载能力不足（实测约 2V），带不动电机。
- **PWMA = PWM 调速**：LEDC 8 位占空比（0~255），AIN1/AIN2 决定方向：
  - `motor_set_speed(正数)` = 正转，`motor_set_speed(负数)` = 反转
  - `motor_break()` = 短路制动（急刹）
- 引脚定义在 `components/Monitor/Monitor.h`：AIN1=8、AIN2=9、PWMA=10，PWM 频率 10kHz。
- **面包板注意**：一个 GPIO 只接一个信号，不要在同一行撞车（之前 GPIO8 和模块 PWMA 共行，一个脚同时驱动两个信号导致电机不转）。
- 语音指令：`motor_on` / `motor_off`（服务器检测"电机转/电机启动"等）。
